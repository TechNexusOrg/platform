# Security Policy

## Reporting Security Issues

We take the security of TechNexusOrg and its contributors seriously. If you believe you have discovered a vulnerability, please do NOT file a public issue.

Instead, please report responsibly to:
**security@technexus.org** or via private GitHub Security Advisory at `https://github.com/TechNexusOrg/platform/security/advisories`.

Please include:
- Detailed steps to reproduce
- Threat model and potential impact
- Any suggested remediations

We will review your submission promptly and coordinate a patch and release before public disclosure.
